# DaniArtesQueEncanta

Site profissional e responsivo para apresentação de trabalhos de artesanato, personalizados e produtos manuais — feito com carinho para a Dani!

Link: https://artesquencanta.netlify.app/

---

## O que oferecemos

- Peças feitas à mão com todo amor e dedicação
- Personalização total: você escolhe cores, modelos, frases e detalhes
- Qualidade garantida em cada peça produzida
- Produtos: Necessaires e bolsas, camisetas personalizadas, canecas, laços e muito mais

---

## Tecnologias utilizadas

- HTML5 — Estrutura semântica da página
- CSS3 — Estilização, design responsivo, cores e animações
- Font Awesome — Ícones elegantes
- Netlify — Hospedagem gratuita e rápida na web

---

## Funcionalidades

- Layout adaptado para computador e celular
- Imagem de fundo fixa que aparece por trás de todas as seções
- Blocos com transparência para valorizar a imagem de fundo
- Botão direto para conversar no WhatsApp
- Navegação simples: Início | Produtos | Diferenciais | Sobre | Contato
